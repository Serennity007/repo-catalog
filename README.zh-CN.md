python scripts/build_catalog.py --offline --check

在线更新需要 Python 3.11+ 和已登录的 GitHub CLI（`gh auth login`）；离线生成和测试只用 Python 标准库。[更新工作流模板与分类规则](docs/maintenance.md)。
